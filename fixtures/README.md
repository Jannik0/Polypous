# Test fixtures

- `small/`: committed fixtures (< 1 MiB each, < 50 MiB total), organized by area (`ops/`, later
  `quant/`, `tokenizers/`, …). Op fixtures are `small/ops/<op>/<case>.safetensors` with a
  `<case>.json` sidecar, generated by `tools/reference/gen_ops.py`. Never edit them by hand.
- `manifest.json`: large fixtures and test models (URL, SHA-256, size, license), downloaded into
  `cache/` (git-ignored) by `tools/reference/fetch_fixtures.py`.

See [docs/testing-strategy.md §3](../docs/testing-strategy.md#3-reference-fixtures) and
[tools/reference/README.md](../tools/reference/README.md).
