# Test fixtures

- `small/`: committed fixtures (< 1 MiB each, < 50 MiB total), organized by area (`ops/`, later
  `quant/`, `tokenizers/`, …). Op fixtures are `small/ops/<op>/<case>.safetensors` with a
  `<case>.json` sidecar, generated by `tools/reference/gen_ops.py`. Never edit them by hand.
- `small/mnist/`: the MNIST training test (testing-strategy.md §3.8, #84): the CNN graph and its
  training config, the reference graph (dropout at `p = 0`) and config, the reference's initial
  weights and its expected losses, all written by `tools/reference/gen_mnist.py`. The configs read
  the MNIST data from `cache/mnist/` and write checkpoints to `cache/runs/`.
- `manifest.json`: large fixtures and test models (URL, SHA-256, size, license), downloaded into
  `cache/` (git-ignored) by `tools/reference/fetch_fixtures.py`. `mnist-train` and `mnist-test`
  are MNIST (CC BY-SA 3.0, Yann LeCun and Corinna Cortes) converted to safetensors by
  `tools/reference/convert_mnist.py`, hosted on the Polypous release `fixtures-mnist-v1`:
  `python tools/reference/fetch_fixtures.py mnist-train mnist-test`.

See [docs/testing-strategy.md §3](../docs/testing-strategy.md#3-reference-fixtures) and
[tools/reference/README.md](../tools/reference/README.md).
